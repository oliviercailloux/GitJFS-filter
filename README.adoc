Decorators for Git file systems.

== Decorators for end users
- `GitPruningFs.prune(delegate, predicate)`: Given a GitFileSystem, returns a GitFileSystem with a pruned DAG of commits: those that satisfy the given predicate are removed from the DAG, and their children as well.
- `GitDaterFs.date(delegate, dater)`: Given a GitFileSystem, returns a GitFileSystem that changes the commit dates according to the `dater` function.

== Helper decorator
Package `io.github.oliviercailloux.gitjfs.wrapping` provides a decorator that can be used as a basis for implementing other decorators.
